# Fonts

Mosign looks for these files here and falls back to system fonts if they are missing:

- `MadimiOne-Regular.ttf`: the "Mosign" wordmark in the window header
- `Outfit-Regular.ttf` and `Outfit-Bold.ttf`: all other text

Get them free from Google Fonts (both are under the SIL Open Font License, which allows bundling):
https://fonts.google.com/specimen/Madimi+One and https://fonts.google.com/specimen/Outfit

For Outfit, use the files from the `static` folder of the download. If the names have a suffix
(for example `Outfit-SemiBold.ttf`), rename the weights you want to the names above.
